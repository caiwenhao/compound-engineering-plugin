# Initialize Project for AI Agents

Scan the current project and generate `AGENTS.md` (canonical) + `CLAUDE.md` (shim) to give AI agents the context they need to work effectively in this codebase.

## Pre-flight Check

Before doing anything, check if `AGENTS.md` or `CLAUDE.md` already exists:

```bash
ls AGENTS.md CLAUDE.md 2>/dev/null
```

If either file exists, STOP. Inform the user:

> "Found existing `[filename]`. To avoid overwriting your configuration, `ce-init` will not proceed. If you want to regenerate, rename or delete the existing file first."

Do not offer to merge, append, or overwrite.

## Phase 1: Project Scan

Gather information about the project using native tools (file-search, file-read, content-search). Do not use shell commands for routine file discovery.

### 1.1 Package/Dependency Files

Look for and read (in parallel):
- `package.json`, `package-lock.json`, `bun.lockb`, `yarn.lock`, `pnpm-lock.yaml`
- `Gemfile`, `Gemfile.lock`
- `requirements.txt`, `pyproject.toml`, `setup.py`, `Pipfile`
- `go.mod`, `go.sum`
- `Cargo.toml`
- `pom.xml`, `build.gradle`

Extract: language, framework, major dependencies, package manager.

### 1.2 Configuration Files

Look for and read:
- Linter configs: `.eslintrc*`, `.prettierrc*`, `.rubocop.yml`, `ruff.toml`, `.golangci.yml`
- Test configs: `jest.config*`, `vitest.config*`, `.rspec`, `pytest.ini`, `phpunit.xml`
- Build configs: `tsconfig.json`, `webpack.config*`, `vite.config*`, `next.config*`
- CI: `.github/workflows/`, `.gitlab-ci.yml`, `Jenkinsfile`
- Docker: `Dockerfile`, `docker-compose.yml`

Extract: code style rules, test framework, build tool, CI pipeline structure.

### 1.3 Directory Structure

```bash
find . -maxdepth 2 -type d -not -path '*/node_modules/*' -not -path '*/.git/*' -not -path '*/vendor/*' -not -path '*/__pycache__/*' -not -path '*/target/*' | sort
```

Extract: source layout, test directory location, config directory.

### 1.4 Git Context

```bash
git remote get-url origin 2>/dev/null
git log --oneline -5
git branch -r | head -10
```

Extract: remote URL, default branch name, branching patterns.

### 1.5 Scripts/Commands

From package.json scripts, Makefile targets, or equivalent:
- Dev server command
- Test command
- Lint command
- Build command

Adapt the content to what was actually detected. Do not fabricate information — if something cannot be determined, omit it or mark it as `<!-- could not detect -->`.

## Phase 3: Generate CLAUDE.md Shim

Write `CLAUDE.md` with a single line:

```markdown
@AGENTS.md
```

## Phase 4: Report

After writing both files, display:

```
Generated:
  AGENTS.md  — project configuration for AI agents
  CLAUDE.md  — compatibility shim (@AGENTS.md)

Please review AGENTS.md and:
1. Verify the detected commands are correct
2. Add project-specific constraints in the Constraints section
3. Add any workflow rules your team follows

The file is ready to commit.
```
